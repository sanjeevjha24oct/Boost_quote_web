RECOMMENDED DISTRIBUTION
Host index.html and these policy files on a secure HTTPS website controlled by Suksun Inc.
Give authorized staff one HTTPS link instead of sending separate copies of the HTML file.

CURRENT TECHNICAL LIMITATION
This v3.4 version stores stock selections and saved quote information locally in each
browser/device. It does not synchronize changes across employee devices.

PRODUCTION RECOMMENDATION
For centralized staff access, inventory, quote history, audit logs, and permissions,
deploy a server-backed version using HTTPS, authenticated staff accounts, role-based
authorization, and a centralized database.

LEGAL NOTE
These documents are practical internal-use templates and are not a substitute for advice
from a qualified attorney. Have counsel review them if the application will handle
significant customer data, be distributed outside Suksun Inc., or be sold/licensed to
other businesses.
